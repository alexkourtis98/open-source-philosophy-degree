# Open Source Philosophy Degree

Welcome to the Open Source Philosophy Degree project!  
This initiative aims to provide free, accessible, and high-quality resources for anyone interested in studying philosophy.

## Goals

- Curate open educational materials on philosophy
- Structure a self-guided curriculum
- Foster a collaborative learning community

## How to Use

1. Explore the recommended reading lists and courses.
2. Join discussions and contribute your insights.
3. Suggest new resources or improvements.

## Contributing

We welcome contributions! Please open an issue or submit a pull request with your suggestions.
